# Аналитика каталога стримингового сервиса

Домашнее задание №1 по курсу «Программирование на Python».

Каталог из 10 фильмов анализируется базовыми средствами языка: числа и `math`,
условия и `match`, циклы, строки, списки, словари, множества, генераторы.

## Запуск

```
uv run catalog_analysis.py
```

Точка входа — `build_report(movies)`: один вызов полностью воспроизводит отчёт
со средним рейтингом, средним возрастом фильмов, топ-3 по рейтингу,
количеством фильмов по жанрам и полным списком жанров каталога.

## Проверка стиля

```
uv run ruff check .
```

Настройки ruff (`line-length = 88`, правила `E`, `F`, `I`) заданы в `pyproject.toml`.
